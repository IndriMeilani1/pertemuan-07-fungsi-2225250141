## Tujuan
Menggunakan fungsi, parameter, return value, dan scope untuk membuat program modular.

## Cara Menjalankan
python3 praktik/utilitas_matematika.py

## Struktur Fungsi
Fungsi luas_persegi_panjang memiliki parameter p sebagai panjang dan l sebagai lebar, lalu mengembalikan hasil perkalian panjang dan lebar. Fungsi luas_segitiga memiliki parameter a sebagai alas dan t sebagai tinggi, lalu mengembalikan hasil perhitungan setengah dikali alas dikali tinggi. Fungsi jumlah_n memiliki parameter n sebagai batas angka yang akan dijumlahkan dari 1 sampai n, lalu mengembalikan hasil penjumlahannya. Fungsi faktorial memiliki parameter n sebagai bilangan yang akan dihitung faktorialnya, lalu mengembalikan hasil perkalian bilangan dari 1 sampai n. Sementara itu, fungsi tampilkan_menu tidak memiliki parameter dan tidak mengembalikan nilai karena fungsinya hanya untuk menampilkan pilihan menu program ke layar.

## Hasil Pengujian
Berdasarkan hasil pengujian, pada fungsi luas persegi panjang dengan input panjang (p) = 8 dan lebar (l) = 5, hasil yang diperoleh adalah 40. Pada fungsi luas segitiga dengan input alas (a) = 10 dan tinggi (t) = 6, hasilnya adalah 30.0. Pada fungsi jumlah 1 sampai n dengan input n = 10, hasilnya adalah 55. Pada fungsi faktorial dengan input n = 5, hasilnya adalah 120, sedangkan ketika input n = 0, hasilnya adalah 1. Semua hasil aktual tersebut sesuai dengan hasil yang diharapkan, sehingga status pengujian dinyatakan berhasil.

## Refleksi
Menurut saya, bagian program yang menjadi lebih sederhana setelah dipisah menjadi fungsi adalah bagian perhitungan luas persegi panjang, luas segitiga, jumlah angka dari 1 sampai n, dan faktorial. Dengan adanya fungsi, setiap perhitungan memiliki bagian masing-masing sehingga program lebih rapi, mudah dipahami, dan tidak perlu menulis kode yang sama berulang kali. Selain itu, jika ingin menggunakan perhitungan yang sama, saya hanya perlu memanggil fungsi tersebut dan memasukkan nilai yang dibutuhkan.
